# Third-party material

What in this repository was not written for it, where it came from, and what
is deliberately left out.

## In the repository

| Files | Origin | Terms |
|---|---|---|
| `bsp/classpad*/FILES/legacy-mfc/*.dll` (`mfcce300`, `olece300`, `mfcce211`, `olece211`) | Microsoft MFC and OLE runtimes for Windows CE, copied unchanged from the eMbedded Visual Tools 3.0 CD (directories and SHA-256 sums in that folder's README and `SHA256SUMS`) | Microsoft's; redistributable only under the eMbedded Visual Tools licence |
| `bsp/kernel/*.patch` | patches to the Windows CE kernel (Shared Source); the context lines are Microsoft's code | Microsoft Shared Source licence |
| `docs/design/art/xp-flag.jpg`, `docs/design/art/ce50-header.png`, and the pictures made from them in `dbt/hhk/art_data.c` and `docs/design/loader-luna.html` | the Windows XP flag and the "Microsoft Windows CE 5.0" lettering | Microsoft's artwork and trademarks |
| `dbt/hhk/font_data.c`, the font tables in `docs/design/loader-luna.html` | 1-bit renderings of Tahoma and Trebuchet MS at a few pixel sizes, made by `tools/mkbitmapfont.py` from the fonts macOS ships | the typefaces are Microsoft's |
| `bsp/classpad*/SRC/APPS/PLOTTERZ/upstream/` | Plotter-Z, salvia89 and pine89 by anderain (commits in `PLOTTERZ/README.md`), with the local changes listed there | MIT according to each project's README |
| `dbt/rt/lcdfont.h` | 4x8 console font generated by `tools/bdf2font.py` from JiZhi-bitmap-8.bdf | MIT |
| `bsp/classpad50/SRC/INC/classpad_pwrseq.h` | register sequences recorded from the power-off and power-on routines of Casio's OS 02.01.7003 by `tools/casio_poweroff_tables.py` | hardware set-up values, no Casio code |

Addresses, register values and behaviour of Casio's OS quoted in the
documents and comments come from reading and tracing the OS on the author's
own calculators.

## Not in the repository

- **Windows CE and Platform Builder.** The BSPs are built against an
  installed Platform Builder 5.0 (or 6.0 R3); `NK.bin` and `EXT.bin` are
  products of that build and are ignored by git.
- **Math Xpander** (Saltire Software, 2001). `tools/windows/claude-build/stage.py --xpander`
  copies its files from an unpacked `Xpander.PPC300_10003.cab`
  (`bsp/classpad50/FILES/xpander/README.md`).
- **SpreadCE** (Bye Design Ltd, shareware). `tools/sh3prep.py` prepares the
  2.05 Pocket PC SH3 build (`bsp/classpad50/FILES/spreadce/README.md`).
- **Casio's OS**, flash dumps and anything derived from them beyond the
  table above.
- **casio-emu**, gint, fxSDK and HollyHock 3, which are separate projects.
